# 验收门槛（实施前定义）

下列均为目标，完成后在实测报告中附结果，未验证不得打勾。

- [ ] 三个领域可编辑真实输入和策略，并执行新案例。
- [ ] 候选执行与独立参照交叉验证；正确策略无已知误报。
- [ ] 每个已确认反例满足约束，且能独立重算失败。
- [ ] 缩减保持约束和同一失败条件，展示真实缩减步骤。
- [ ] 未发现、有限穷尽、超限/取消、反例成立状态准确区分。
- [ ] 双轨每一步与事件/最终结果一致；支持单步、回退、跳转。
- [ ] 策略修正形成新版本，保留旧结论，能跑历史和保留集。
- [ ] 搜索可取消、资源有界，界面不被计算阻塞。
- [ ] 实验保存、恢复、导入导出、HTML报告可用，数字和条件一致。
- [ ] 无密钥时本地核心可用；有密钥时真实模型调用及失败路径实测。
- [ ] 模型输出只能形成受限数据，不能执行任意代码。
- [ ] 真实界面使用原创生成视觉参考/素材，交互不是图片上的假按钮。
- [ ] 桌面与小屏、键盘、减少动画、空/错/载入状态检查通过。
- [ ] 凭据扫描通过，运行数据不进入Git。
- [ ] 独立干净环境10分钟运行记录，说明前置和计时边界。
- [ ] 至少三条核心真实迭代链能够对应Git和测试记录。
- [ ] 最终源码与GitHub一致，已知限制公开，视频/PDF暂不制作。

性能先记录设备、输入规模和预算，分别报告编辑、渲染、搜索、模型耗时。以实测调整支持范围，不虚构已达指标。
