# CounterLab 完整开发方案

状态：实施基线；2026-11-15。所有未完成的指标均为验收目标，而非现有成绩。

## 1. 产品目标与用户

面向算法学习者、程序设计竞赛学生和小型策略设计者，帮助用户判断一种策略在什么条件下会失效，找到足够简单且能亲自检查的反例，比较执行过程，修改策略并检验是否发生退化。

主闭环：自然语言/手工规则 → 明确的实验契约 → 本地真实搜索 → 独立验证 → 保持性质的缩减 → 双轨执行与解释 → 修改版本 → 原例/历史/保留集复验 → 保存和导出。

作品主要对应赛事方向5“AI驱动的高交互教育与可视化”，结合方向4的自然语言生成交互工具。产品自研，不以现成同类应用作为二次开发底座。通用数学思想、基础库、模型与素材如实署名；不宣称反例搜索思想为本项目发明。

## 2. 原创产品机制

1. 意图转换形成可读、可编辑、可确认的契约，明确域、目标、输入限制、策略、平局与边界语义。
2. 从复杂失败实例中逐步剥离无关对象和数值，每一步重新检查合法性与同一失败谓词。
3. 候选策略与参考解使用同一输入，展示真实事件、首次分歧、被排除对象及目标变化。
4. 用户修改约束和策略形成新版本，保留原始结论，不覆盖旧实验。
5. 修正后同时复验原反例、历史反例与独立保留样本，显示改善和退化。
6. 导出包含输入、契约、版本、种子、执行器版本、结果与轨迹的实验包，可导入并重新验证。

## 3. 首发三个领域

### 区间调度
任务为不可拆分的半开区间 `[start,end)`，端点相接允许。支持最多任务数/最大收益两个明确目标。用户可编辑排序字段、方向、平局规则和接受条件。参考采用精确动态规划，小规模另以独立子集穷举核验。

演示：A=[0,4),收益9；B=[0,2),收益6；C=[2,4),收益6。收益优先选A得9，B+C得12。它是可运行例子，不是预制搜索结果。

### 0-1 资源分配
整数正重量、非负价值、整数容量，每件最多一次且不可拆分。支持价值、重量、价值密度等排序及明确平局规则。密度比较避免浮点边界错误。参考采用精确动态规划/小规模枚举，明确规模上限。

### 非负权图路由
带节点ID、非负整数权重、明确起终点和有向性。支持合法的可编辑路由策略，含局部选择与全局距离优先等语义。区分不可达、策略陷入死路、超步数、可行但非最短。参照最短路与独立简单路径枚举/Bellman–Ford交叉检查。

## 4. 完整功能

实验首页、示例与导入；自然语言意图输入；规则编辑与确认；可编辑任务/物品/图；可取消的搜索；逐步缩减轨迹；候选/参照播放器；策略版本与比较；历史反例和保留集回归；实测结果地图；自动保存、恢复；实验包与HTML报告导出。

不把任意通用程序、无限规模、通用数学证明纳入首发承诺。用户必须能够实质修改策略与输入，不能只播放硬编码经典反例。

## 5. 视觉与交互

用户最新要求：复杂界面使用内置 image-2/图像生成能力制作原创高质量视觉稿和关键素材，避免简单图形拼接的粗糙观感。视觉稿用于设计，所有规则、图表、按钮、轨迹与数据须实现为真实可交互组件。

方向：精密实验仪器与编辑工作台结合。暖白瓷色背景、墨色文本、朱红主强调、克制的钢蓝参照色，精细刻度、统一对象标识、优秀中文排版。工作台分策略/场景/证据区域，配底部时间轴。支持空状态、错误、加载、取消、恢复、键盘操作和减少动画；颜色以外有状态文字。

动画由真实执行事件驱动，图形与检查器不能各自计算不同过程。首次分歧不自动等同因果原因；解释需有实际干预或计算依据。

## 6. 技术与模块

- React + TypeScript + Vite；SVG/Canvas 领域交互。
- Node.js + Fastify；本地同源后端，不要求云服务。
- SQLite 保存项目、契约版本、运行与设置；运行数据不入Git。
- 自研类型化、有界的策略表示和解释器。禁止 eval、新函数编译和执行模型生成代码。
- Worker 执行搜索、缩减和参考计算；主服务保持响应。Worker 不宣称是任意代码安全沙箱。
- AI适配层分离供应商、地址、模型、超时、重试和用量。没有密钥时保留本地核心功能。
- Python 仅作开发期独立参照验证；发行包无需安装Python。
- 固定依赖、固定语义版本、固定种子和输入文件。多版本兼容明确迁移或拒绝，不静默改写。

模块边界：contracts/types → domains/execution/oracles → search/shrink/verification → traces/replay → persistence/jobs/AI → frontend。

## 7. 正确性与结果状态

每个反例必须满足输入约束，候选轨迹可重算，参考解可行，且确实违反所确认主张。

结果区分：`counterexample`（已独立核验）、`bounded_pass`（明确有限空间穷尽）、`not_found`（采样未找到）、`incomplete`（超限/取消）。参考求解未完成不标最优。没有完整最小性验证，仅称已缩减/对指定操作不可再缩减。

数值安全范围、平局、对象ID、时间端点、不可达状态、相等值、零权重等都必须明确。输入错误、模型格式错误和计算中断不能被归并为无反例。

## 8. AI职责与成本

模型负责意图理解、缺失条件提示、候选契约、证据解释和待验证修改建议。程序负责执行、搜索、判定、缩减、数值与重放。批量搜索不逐例调用模型。

按用户提供的DeepSeek V4.1 Flash 1017系列接入，正式调用前核验密钥所属服务地址。官方平台当前调用名为 deepseek-flash；不能将未知平台密钥发送到猜测地址。真实密钥不写前端、日志、Git或证据。

基础设施目标支出0：使用现有电脑、开源依赖、本地数据库。模型联调按几十元级目标规划、记录实际用量、限制重试；实际费用以服务商为准。不默认租服务器、购买硬件或增订服务。

## 9. 质量验证

每域建立正确/错误/条件遗漏策略与边界集；开发样例和保留集分离。独立参照不能逐行复制产品引擎。每个显示为成立的反例都重新验证。缩减每步验证合法性与原谓词。所有图形/报告数字关联真实执行结果。

验证项目：数值和边界、策略解释、参照一致、误报、搜索覆盖、缩减、修改退化、存档迁移、API校验、恶意结构、资源上限、取消恢复、模型失败、UI无障碍与完整流程。性能绑定硬件和问题规模，模型延迟单列。

不要求大规模真人试用。可客观验证功能和计算；没有研究数据不宣传学习成绩提升。已知错误结论、数据丢失、无法恢复等阻断缺陷为0，其他限制列入报告。
