# 已知边界

## 支持的实验范围

- 区间：1–16 个任务，整数时间 0–10000，结束必须大于开始，收益 0–100000；半开区间，端点相接允许。
- 0-1 背包：1–18 个物品，重量 1–10000，收益 0–100000，容量 0–10000；每件最多一次。
- 图：2–12 个节点，至多 80 条边，权重 0–10000，节点坐标 −10000 至 10000；不支持负权、自环和重复边。
- 单次采样最多 2000 个实例，随机生成数值上限 100。手工输入的合法范围更大，因此采样未发现反例不能覆盖全部手工输入空间。
- 策略支持领域相关的受限算术评分和明确算法，不接受任意程序、函数调用、脚本或外部代码。

## 结论的确定程度

搜索是固定种子的有限采样。没有实现有限空间穷尽模式，不会发出全域正确性证明。最早结束的贪心策略对「最多不重叠任务」的经典条件适用，但不能把这一点推广到带权收益；应用仍会对每次具体实验计算。

缩减对指定的删除、取最小值、折半和减一操作寻找局部稳定点，有 4000 次检查上限。显示「对这些操作局部不可缩减」不意味着全局最小；取消、超限或导入历史结果时，只显示已缩减。

双轨使用各自真实执行事件，以步号联动。两种算法的第 k 步不一定处理同一对象；首次选择分歧仅是观察，不构成因果证明。精确策略的内部状态数量和贪心事件数可能不同。

## 运行与成本

当前交付优先验证 Windows x64、D 盘本地使用。服务仅监听 127.0.0.1；不是多用户云服务，没有账户系统或远程协作。便携包在 C 盘运行会被拒绝，以遵守本次文件保护要求。没有云服务器费用。

浏览器的站点数据受所用浏览器管理；开发自动化使用 D 盘独立浏览器缓存。生产源码和便携包不会自动启动用户的默认浏览器或修改系统配置。

AI 是可选在线功能，按官方 API 计费。没有密钥时所有本地算法流程可用。当前服务会话最多 100 次模型请求，每次最多 1800 输出 token、30 秒超时。AI 文本可能出错，不能代替程序结论；所配置服务不可用时必须重试或使用手工策略。

## 存档与开发证据

单个实验最多 200 个修订，保存体积约 16 MiB，超限会明确拒绝。回归纳入原例、最多 20 个同领域历史反例，以及至多 100 个独立生成样本；没有声称已复验整个历史库。实验包不兼容执行器版本时拒绝导入，不静默迁移。

保留真实 Git 演进和脱敏后的可见对话/工具记录，不包含模型私有推理。自动整理的开发摘要与原始记录分开标注；代理之间的指令属于 AI 代理协作，不冒充参赛者本人提出的修正。比赛所需的本人 AI 协同展示、视频和 PDF 仍需在最终提交阶段完成，当前按用户要求暂不制作视频和 PDF。

未开展大规模真人教学试验，不能据此宣称提高了某个百分比的学习成绩。自动化、独立计算和视觉检查验证的是当前功能与计算，不能保证奖项或评审分数。
