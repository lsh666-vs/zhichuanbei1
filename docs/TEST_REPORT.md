## 视觉、无障碍与时间

实际检查桌面 1536×1080 和手机 390×844。桌面计算结果与帮助对话框的 axe WCAG 2 A/AA、2.1 AA 标签检查无违规；手机文档宽度 390，与视口相同。局部轨迹容器有意横向滚动，以保持标签可读。手动查看真实截图确认横幅、双轨、证据区和底部导航。自动检查不能替代全部辅助技术人工测试。

一次本机真实浏览器测量：页面可操作 182 ms，区间计算点击至结果 82 ms，时间轴跳转 21 ms。包含自动化与 HTTP 开销，是单次观测，不是渲染性能分析或响应时限承诺。引擎在 2000 个最大生成规模样本上的观察耗时为区间 84 ms、背包 125 ms、图 448 ms；输入、预算和方法见 `evidence/engine-development.md`。

图形组件另有独立浏览器检查：负坐标、SVG 留白下拖动逆变换、拖动投影冻结、双轨对象联动、节点与边同名、Enter/Space/Escape、方向键移动均完成；独立组件验证与整页验证明确区分。

## 实际发现和修复

1. API 收益上限误拒绝合法大值；改正边界并覆盖最大值。
2. 大图回归超过旧请求上限，无法保存；提高受控上限，增加超过 4 MiB 的完整往返测试。
3. 图死路的占位 0 曾导致回归/报告误读；改用路径完成语义，显示未到达 / 不可达 / 差距不适用。
4. 伪造排列不能作为缩减，缩减链逐步复核；搜索早停进度在完成时刷新。
5. 字体低对比、横幅尺寸、窄屏标签和焦点恢复；按真实浏览器结果修正。
6. 快速刷新丢失草稿、领域切换覆盖草稿、未完成表达式无法恢复；增加退出刷新、领域缓存与编辑态恢复。
7. 缩减后旧 AI 解释残留、节点/边同名引起错误高亮、任务 404 导致永久锁定；增加对应回归检查。
8. Windows PowerShell 5 默认编码破坏 Unicode 清单路径；清单显式按 UTF-8 读取。
