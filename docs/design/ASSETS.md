# 原创生成视觉与使用

本目录 `workbench-reference-v1.png` 是内置 image generation 生成的界面设计参考，不是产品已完成截图；图中统计数字、流程状态及导出类型均不代表真实功能或实测结果。

`public/assets/counterlab-hero.png` 是基于同一视觉方向生成的无字玻璃丝带图，供实际页面背景使用。按钮、标题、图表、数值、轨迹与编辑组件由真实代码实现。

两次生成均在用户明确允许本次图片新增的情况下进行，选定文件复制至D盘；没有删除或修改C盘原始图片。

## 原始提示词摘要

主稿：CounterLab中文高品质桌面实验工作台；暖瓷白、墨黑、朱红与钢蓝；侧栏、任务规则、双轨区间时间轴、证据区与播放器；透明玻璃丝带及朱红细丝的原创背景。完整生成提示词可见脱敏的可见开发记录快照。

素材：独立3:1无字宽图；暖白背景；右部透明烟灰玻璃丝带及朱红细丝；左部留白供HTML标题；精细折射与柔和光照；无界面、无文字、无商标。

生成方式：内置 image_gen（用户要求 image-2 视觉），未使用CLI/API付费备用路径。
