# 真实应用截图

`workbench-desktop.png` 和 `workbench-mobile.png` 来自实际构建后的 CounterLab 页面，分别使用 1536×1080、390×844 视口。图片显示真实运行的 A=9 与 B+C=12 的区间实验，时间轴已跳至结束；图中的按钮和图表均为实际组件。

手机图为完整页面截图，因此固定底部导航出现在首个视口底部对应位置；实际滚动时它保持在视口底部。轨迹图在容器内横向滚动，保持文字可读，不造成页面横向溢出。

检查脚本：`scripts/inspect-ui.ts`。背景横幅由内置图像生成工具原创生成；它与实际数据图层分开。设计参考不是运行截图，见 `docs/design/ASSETS.md`。
