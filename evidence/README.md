# 真实开发证据

本目录保存真实开发决策、原始指令摘录、实际验证和修正记录。**整理摘要不是原始完整对话导出**，两者必须标明并分开保存。当前仍需在交付前核验完整对话导出/截图是否齐备。

可用索引：[三条真实迭代链](ITERATION_CHAINS.md)、[引擎记录](engine-development.md)、[后端记录](server-development.md)、[界面记录](ui-development.md)、[图形组件独立复核](ui-component-review.md)。原始可见历史见 `visible-history-20261115.json`，开发早期快照见 `visible-development-snapshot.json`。它们仅导出可见消息和动作，凭据脱敏，私有推理排除，存在各自标注的截断边界。

最新导出为 `visible-history-20261116.json`：读取工具返回的全部历史分页，共15个可用回合；单项最多20000字符。它保留开发过程截至导出时的可见记录，不能因此宣称没有会话压缩或截断。

每条核心链链接：需求 → 真实可见对话或可验证指令 → 修改 → commit → 测试 → 后续修正。每次提交不要求人为制造Bug；只记录实际发生的问题。

原始记录含秘密时必须先脱敏，记录脱敏理由，禁止将完整API key或SSH私钥写入任何可提交文件。时间按实际记录，不伪造历史。代理参与标注为代理，不冒充用户。

重点链：
1. 契约表示与意图一致性。
2. 反例搜索、独立验证与性质保持缩减。
3. 执行事件、交互解释、修正和重放。
