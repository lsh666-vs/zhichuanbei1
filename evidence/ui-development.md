# 工作台界面实现与复核记录

日期：2026-11-15。本文记录本轮实际完成的前端工作，不是用户访谈、外部测试或模拟开发对话。

## 视觉依据与实现

- 已实际查看生成的视觉参考 `docs/design/workbench-reference-v1.png` 和独立横幅 `public/assets/counterlab-hero.png`。
- 采用暖象牙底色、墨绿黑导航、朱红候选轨迹和钢蓝参照轨迹。横幅使用真实图片资产；策略字段、结果、执行轨迹、进度与按钮均为真实组件，不把效果图作为界面。
- 三栏工作台分为策略定义、双轨运行与搜索、证据与修正。中等屏幕重排证据栏；移动端顺序阅读，四项导航固定到底部。
- 移动端轨迹画布设最小宽度并在自身容器内横向滚动，防止 SVG 标签被缩成不可读小字；页面本体不依靠整体横向滚动。
- 完整补齐输入编辑、实验档案、历史版本、执行记录、缩减步骤、复验结果、实验手册、AI 提案确认等弹窗样式。

## 可操作组件改进

- 输入编辑器保留受控字段，所有更改需通过应用输入才进入工作台；数值契约由前端与服务端验证，错误不伪装为计算结果。
- 区间最多 16 项、背包最多 18 项、图最多 12 节点和 80 条边。达到数量边界禁用添加；背包容量允许 0；数值输入声明整数步进及契约上下界。
- 添加图边时选用尚未连接的合法端点对，不再默认插入可能重复的首尾边；没有可用连接时禁用添加。现有边被手动编辑成自环或重复边时仍由应用输入验证明确拒绝。
- 原生 dialog 提供焦点限制与 Escape 关闭，并添加唯一 `aria-labelledby` / `aria-describedby`。集成检查发现卸载后原生焦点恢复不稳定，已显式记录唤起控件，在对话框关闭后恢复焦点；兼容 React StrictMode 的重复 effect。背景点击只在实际对话框矩形之外关闭。
- 双轨图的负坐标投影、拖动稳定性和联动高亮由团队另外一轮组件修复完成，细节见 `ui-component-review.md`。

## 已观察到的验证与迭代

1. 本轮组件与样式格式化后，实际运行 `node node_modules/typescript/bin/tsc --noEmit`，返回成功。
2. 团队首轮集成检查通过真实编辑、运行、保存/版本、复验、搜索/缩减、导出/导入与三领域输入流程；无障碍检查指出文字对比不足，未将这一轮写成全部通过。
3. 按实际失败截图修正了横幅原图尺寸与层级、标题区域重叠、侧栏挤压，以及辅助文字与朱红按钮对比。项目主代理随后报告构建通过、axe 无违规、390px 页面无横向溢出。
4. 实际查看了 `.runtime/ui-inspection/desktop.png` 和 `mobile.png`。依据移动端截图进一步改为底部导航，并让轨迹画布局部滚动；最终的全量端到端检查与截图由项目主代理执行，结论以其最终测试记录为准。

## 事实边界

执行值、执行步骤与结论来自 API 实际返回。示例反例和搜索结果不是视觉效果图里的固定数字。AI 提案需确认，AI 文字解释不替代独立计算；没有密钥时核心计算仍可运行。此文没有声称已经开展学生群体测试，也没有把自动化测试当作真实用户研究。
