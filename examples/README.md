# 可重放实验样本

这三个 JSON 是运行 `node --import tsx scripts/generate-examples.ts` 真实生成的实验包，可从应用的导入入口打开。它们是固定种子的演示样本，不冒充评委现场输入或新的搜索结果。

生成参数：种子 20261115、至多 300 个样本、规模 7、生成数值上限 20。区间、背包、图分别在第 2、5、1 个实例找到反例。随后实际执行 26、32、11 个接受的缩减步骤，并与精确策略进行原例 + 12 个保留样本的比较。三个包均已经过导出→导入→重算检查。

包中时间戳和 UUID 每次不同；同引擎版本、输入、策略与种子对应的计算结果可重放。缩减导入后只保留「已缩减」结论，不能凭包内历史统计重新宣称局部最小。SHA-256 校验和用于检测文件改变，不是数字签名。

除这些样本外，工作台可以编辑新输入和新规则，也可以换种子重新搜索。最大支持范围与随机生成分布见 [引擎记录](../evidence/engine-development.md)。
