# 光铸 LightForge — 完整开发与验收方案

版本：2026-11-16，用户选定光子芯片逆向设计，并明确要求三维交互、质量优先与三个串行交付阶段。本文件记录计划，不代表功能已经实现。

## 产品目标

面向光电、物理、电子专业高年级学生、研究入门者及课程教师，完成「自然语言目标 → 可检查的物理规范 → 器件设计 → Maxwell 求解 → 伴随解释 → 约束优化 → 制造扰动 → 独立验证 → 可复现实验导出」。旗舰实验为双波段氮化硅光子分波器；波段、端口、设计区域、工艺与性能条件可修改。范围为无源、线性介质的平面集成光子器件，实际结构与物理场采用三维模型。

四项核心能力均必须交付：电磁场方程、伴随梯度、约束优化、制造鲁棒性。截止日期不授权降低验收标准。未完成或未验证项目必须明确标注。

## 交互是必须验收的产品能力

最终交付必须是可编辑、可操作、可重算、可比较、可继续实验的应用。静态图、生成图片、单向报告、视频和预计算回放只能辅助教学，不能单独满足功能完成条件。具体操作脚本见 `INTERACTION_ACCEPTANCE.md`。

四项核心均需形成交互闭环：修改物理条件后求解 Maxwell 场；在三维区域提出扰动并比较伴随预测与实际重算；改变约束并控制优化、回看迭代和继续分支；调整三维制造误差并评价扰动性能。用户须能离开内置示例，创建经过校验的新实验。

观察交互（旋转、剖切、显示分量、探针和色标）读取对应计算数据，不要求重复求解；物理编辑（几何、材料、激励、工艺和约束）必须生成新规范并触发可控的真实计算。计算期间清楚展示预览、旧结果所属版本、新任务状态；结果不匹配时不得把旧场贴到新结构。

每项交互都要记录输入动作、可观察反馈、实际数据/计算变化和端到端测试。验收必须实际点击、拖动、输入、取消、刷新恢复和复算，不能只检查页面有按钮。正式三维工作台不能以第一阶段科学诊断页代替；诊断页自身的旋转和真实切片控件也须实测。

## 三维交互

1. 层结构：旋转、隐藏、剖切、爆炸展开；爆炸展开只影响观察，不改变物理层间距。
2. 三维参数编辑：层厚、刻蚀深度、侧壁角、端口尺寸、设计区域；受工艺约束的手柄与精确数字输入；撤销/重做/版本保存。
3. 端口模态：在真实端口截面上查看模式、场分量、归一化与输入条件。
4. 场工作台：真实 3D E/H 数据、任意剖切、体渲染、等值面、空间探针、能流；场强不能替代端口效率。
5. 伴随：同步正向/伴随/敏感度三视图，选区小扰动，一阶预测与实际重算对比；参数导数不伪装成力。
6. 优化：真实迭代时间轴、新增/移除材料、约束位置、版本分支；二维曲线联动到三维位置。
7. 制造：过/欠刻蚀、薄膜厚度、刻蚀深度、侧壁角、相关边界粗糙度与材料变化；重算前不得把旧场贴在新结构上。
8. 验证对比：同步相机、剖切、探针、色标；复数场比较统一激励、参考相位与归一化。

统一坐标为 x/y 平面、z 厚度，用户单位 μm，内部归一化及 SI 换算明确。显示网格与求解网格来自相同规范。二维计算不得挤出伪装成三维场。查看结果与重新求解采用不同状态。

## 科学路线

实施变更（2026-11-16）：原选 NGSolve/Netgen 的原生 OCC DLL 被本机应用控制拒绝加载，实际主路线改为 Windows 原生三维矢量 Yee/FDFD；NGSolve 保留可选。下文有限元选型为原批准方案，当前实施以 `IMPLEMENTATION_DECISIONS.md`、`CONTRACTS.md` 和 `science/STAGE_1_NUMERICS.md` 为准。此变更保留三维物理与全部最终验收标准，不以二维场替代。实际开放 SiN 脊波导精度尚有缺口，必须在发表器件指标前解决。

时间约定 exp(-iωt)。求解 curl(μr^-1 curl E) - k0² εr E = iωμ0 J。主 3D 路线采用 NGSolve H(curl) 矢量有限元、Netgen 网格，公开库是基础设施，原创部分为问题建模、设计映射、优化与教学流程。开放边界/波导端口必须单独验证，不从标量示例推断 Maxwell 正确性。Meep FDTD 用作独立复核；2D FDFD用于基准、快速探索与近似误差教学。

离散问题 A(θ,ξ,ω)e=b。伴随采用与实际离散一致的复数导数与共轭约定；显式处理端口和归一化对参数的依赖。滤波、投影、几何映射进入链式求导。方向有限差分和 Taylor 检验必须通过。

采用密度/几何参数化、空间滤波、连续投影、MMA 与多波长多情景 epigraph 最坏情况优化。优化端口、掩模和固定区域明确；最终二值几何独立检查最小线宽、间距、孤立细小结构和刻蚀规则，修复后重算。只称局部求得的可行解，不称全局最优。

制造扰动实际改变三维材料/几何，并参与鲁棒目标。测试样本独立于优化样本，记录种子、分布、相关长度、样本量、失败结果与不确定性。只称所设模型下的仿真通过率，不称真实工厂良率。工艺假设与材料数据来源明确。

## 质量与验收

以下为目标而非已取得的成绩：代表性线性系统归一化残差≤1e-8；无源基准完整功率收支误差≤1%（含辐射/吸收）；已收敛工作点网格/边界变化使主要透射率变化≤1个百分点；平滑代表性方向导数相对误差≤1e-3并通过步长扫描；独立3D模型主要透射率差≤2个百分点并分析例外。PDE、端口、几何和原始场分别验收，不能用残差代替物理正确性。

旗舰设计目标：在冻结的波段、面积、材料、工艺预算下名义目标透射≥85%、隔离≥15dB；所设扰动范围内透射≥75%、隔离≥12dB。未达到必须如实记录并继续设计，不能通过改色标、删失败样本或移动目标达标。

交互验收：计算与显示几何一致、探针/剖切/色标正确、观察操作不改物理、结果不串版本、刷新恢复、取消与失败可定位。约定测试场景主要视图≥30fps，普通编辑反馈约100ms；实际硬件耗时和内存另测。便携包干净环境10分钟内启动并运行小型真实3D任务，不声称10分钟完成全部高精度优化。
