# 策镜 PolicyGlass：完整开发与验收方案

状态：用户于 2026-11-16 批准开发；本文件先于实现提交。面向省赛，质量门槛不因日历缩减。所有完成声明以阶段交接与证据为准。

## 1. 产品与问题

方向：PPO、SAC 神经网络底层机制的真实计算与交互讲解，属于规则中的“AI 驱动的高交互教育与可视化”。用户是已接触神经网络、却难以把强化学习公式、代码与行为联系起来的大学生、研究生、教师和开发者。

主要问题：看到奖励曲线并不能解释某个参数为何更新、梯度为何消失或策略为何退化。产品把一个真实动作、一次经验和一次参数更新连接起来，并允许用户干预后重新计算。

核心流程：创建/打开实验 → 运行真实策略 → 暂停并选择经验 → 展开网络前向 → 查看目标与损失 → 追踪反传与优化器 → 从同一检查点建立对照分支 → 比较数值与后续行为 → 保存笔记与可复现实验包。

四项核心能力全部保留：
1. 一次真实更新的完整计算追踪。
2. 同一检查点上的受控干预和重新计算。
3. 物理行为与网络内部的双向定位。
4. 需要数值证据才能完成的机制实验。

产品包含引导课程和自由实验，不把少数预设案例当作全部可支持内容。无需图像分类模型、外部预训练大模型、付费服务器或 GPU。策略网络和价值网络本身就是训练与解释对象。

## 2. 原创贡献与边界

不宣称发明 PPO/SAC 或全球首个网络可视化。原创设计集中在样本—张量—损失—局部导数—参数梯度—优化器—行为的完整关联，以及在可恢复状态上的单变量干预。详见 COMPETITOR_AUDIT.md。

禁止直接包装已有 RL 教学成品。使用 PyTorch、MuJoCo、React/Three.js 等通用基础库；科学基准可以对照公开参考实现，但产品交互、追踪协议、实验课程和界面独立设计。保留第三方许可证和算法来源。

PPO(2017)、SAC(2018)是基础算法；近年研究联系聚焦实现可靠性、经验复用、休眠神经元与可塑性。不能把老算法的发布时间说成近五年。研究专题用明确假设和真实实验支持，不预设每种配置都会出现某种退化。

## 3. 算法与科学内容

### PPO
- PPO-Clip、GAE、连续动作；另设离散动作微型算例核对概率。
- 输入与归一化、Actor/Critic 前向、策略分布、采样噪声、动作变换。
- 经验、奖励分解、终止/截断、自举与 GAE 时间贡献。
- 冻结旧 log probability、优势归一化、多轮 minibatch、裁剪分支、KL 监测、价值和熵项。
- 样本贡献、共享/独立网络选择、梯度累积、全局范数裁剪、Adam 一二阶矩与实际更新。

### SAC
- 现代连续动作 SAC，双 Q、目标 Q、回放、重参数化、tanh 动作与概率修正。
- 熵修正 Bellman 目标；目标停止梯度；Actor 经 Critic 对动作求导，但不更新 Critic 参数。
- 自动熵温度与目标熵的符号约定；目标网络软更新；回放采样位置和随机状态。
- 区分 Actor、Q1/Q2、目标 Q1/Q2 和温度的更新阶段。

### 共同的真实计算要求
- 使用同一个算法内核训练和生成检查事件；追踪器读取真实张量。
- 所有显示数字有对象 ID、样本 ID、形状、单位/语义、参数版本和来源。
- 反传区分局部导数、链式路径、批次平均、裁剪后梯度和优化器更新。
- 一个样本策略梯度为零不表示所有参数不变；Adam 动量也可能造成变化。
- 不把样本级 Adam 更新相加；样本贡献只在相应线性梯度阶段可加。
- 环境轨迹形成奖励和观测；普通 PPO/SAC 不穿过物理引擎做端到端反传。
- 回退查看与恢复检查点分别处理，不能反向播放即声称撤销优化。
- 标记实时计算/历史回放/续训。预存结果必须来自有来源的真实运行，并可修改后重算。

全部精确定义、符号和可执行不变量见 SCIENTIFIC_CONTRACT.md。

## 4. 三维物理实验

主环境为三关节空间机械臂：基座旋转、肩关节和肘关节，控制关节力矩，完成三维目标到达。MuJoCo 处理质量、惯性、重力、阻尼、关节限位和动力学。观测包含关节状态、末端与目标信息；奖励分解到误差、控制代价与动作变化。单位统一为 SI。

可交互：拖动可达目标、施加有单位和持续时间的外力、检查关节/末端轨迹、改变阻尼或质量后按规定重置，查看分支表现。不可达目标明确拒绝/标记。编辑状态是一次有记录的干预，不伪装成连续物理运动。

物理仿真与显示采用同一几何源；后端发送位置、姿态、时间戳，前端只渲染。插值仅用于显示，不能用于计算物理奖励或替代仿真。检查正运动学、限位、无驱动能量/阻尼行为、时间步长收敛和状态恢复。说明理想刚体模型与真实硬件差异。

## 5. 四处关键 3D 及实现

| 位置 | 坐标/空间意义 | 必须提供的交互 | 真实性验收 |
|---|---|---|---|
| 空间机械臂 | 世界坐标与真实关节几何 | 旋转视角、目标拖动、外力、轨迹、分支对比 | 渲染刚体位姿与 MuJoCo 状态一致 |
| Actor–Critic 结构 | 稳定分层的概念布局 | 模块展开、路径隔离、神经元/边选择、前向/反向逐步 | 结构来自模型；数值来自当前事件；标明非物理空间 |
| SAC 双 Q 曲面 | 两个动作维度与 Q 高度，其他动作固定 | 状态切换、动作维度选择、切片、Q1/Q2/min 对照 | 随机点独立回算 Q；标明固定维度 |
| 局部损失曲面 | theta=theta0+u*d1+v*d2，损失为高度 | 切面、学习率、梯度/更新方向、分支比较 | 固定批次和噪声真实重算；标明只是切片 |

网络默认展示模块，选中后展开到层与单元。大图使用 InstancedMesh、按需连线、稳定布局和路径筛选，完整参数仍能用矩阵检查。不能为了性能悄悄丢掉数值或连接含义。

损失轨迹若投影到平面，显示离面残差；SAC actor 曲面冻结 critic/alpha/噪声，PPO 曲面冻结旧概率/优势/批次。不能把可视化切片称为完整高维曲面。

公式、矩阵、曲线、原始数值继续使用 2D 并与 3D 联动。image-2 只用于封面、课程插画和视觉资产；科学图、梯度箭头和物理轨迹程序化生成。

## 6. 完整界面与用户闭环

首页：创建实验、案例、最近实验、导入包。配置：算法、环境、网络、种子、学习率与资源预算。工作台：左侧步骤/轨迹，中间场景，右侧对象检查器，底部统一事件时间轴。

必须支持：启动、暂停、恢复、取消、保存；选择环境步/训练步/样本/参数；跳到 forward/loss/backward/optimizer；在视图间保留选择；原始值展开与复制；公式带入数值；检查点分支；单变量改动；对照差异；笔记引用事件；导出、关闭、导入、重算。

环境步、优化步、播放时间分别显示。任务有真实运行阶段、队列、进度、错误、重连、取消和恢复状态。未完成任务不能展示为成功。

视觉方向：精细科研仪器，清晰层级、稳定空间布局、克制配色、正负值不只靠颜色区分。保留键盘操作、图例、单位、焦点、减弱动效选项。3D 有二维数值替代视图，但关键3D功能本身仍须实现。

## 7. 八个完整机制实验

每课具备背景→预测→实际操作→数值证据→解释→自由探索→保存。

1. 一个动作如何产生：编辑观测/权重并固定噪声，追踪 Actor 前向。
2. 奖励如何影响过去动作：奖励位置、gamma/lambda、GAE 时间贡献。
3. PPO 裁剪后权重为何仍动：样本/批次/熵与价值/Adam 区别。
4. PPO 为什么更新过猛：学习率、轮数、概率比、KL 与行为。
5. SAC 的 Actor 如何经过 Critic 学习：冻结参数 vs detach 路径。
6. 双 Q 与目标网络各做什么：目标、梯度、软更新对照。
7. 经验复用越多是否越好：实际重新训练、多种子、价值误差与评估。
8. 神经元为何不参与学习：激活统计、梯度、更新量、受控干预。

案例引导不限制自由配置。结果不显著或失败也显示；不通过挑种子伪造稳定结论。课程答案必须能引用事件和检查点。

## 8. 架构与技术栈

前端 React+TypeScript+Vite；Three.js+React Three Fiber+Drei；ECharts/Canvas；KaTeX；Zustand。后端 Python3.12+FastAPI+WebSocket；PyTorch+NumPy；MuJoCo+Gymnasium。SQLite存元数据，JSON存描述，Safetensors存可信数据格式的张量。pytest/Vitest/Playwright。

锁定实际验证的版本，不追逐试验性渲染或框架。CPU 双精度作为科学参考；加速模式明确标记精度并与参考对照。起始网络两层64单元，支持受限的更宽配置。不是通过虚假动画掩盖算力问题。

五个模块：算法内核；计算记录器；物理环境；实验管理器；展示/教学。训练独立进程，API与界面不被长任务阻塞。暂停/取消在明确安全边界生效。Trace大张量按需获取，小控制事件流式发送。

接口与数据契约见 CONTRACTS.md。Stage1 提供稳定Python服务与HTTP契约；Stage2不在浏览器另写一套不同的训练算法。

## 9. 检查点、分支与可复现

检查点保存：网络结构/参数、全部优化器状态、学习率/计数、Python/NumPy/Torch与环境随机状态、PPO rollout及旧概率、SAC回放及采样状态、观测统计、完整物理状态、环境参数、代码与依赖版本。

单步对照固定批次和随机噪声；继续学习对照恢复相同起点后各自采集数据，遵守 on/off-policy 语义。历史产物不可原地编辑；更改配置生成子分支并记录父对象和差异。

长训练周期保存；选中更新完整追踪，其他位置可从最近检查点重算。快照带版本、哈希、边界、有限值和大小校验。不加载 pickle，不执行上传代码，zip路径不允许越界，不接受任意系统路径。

在锁定CPU环境中验证确定性；跨平台声明容差而非逐位一致承诺。原始数据、图表和报告可追溯。

## 10. 讲解助手

第三阶段接入可选的 DeepSeek 官方API。只读当前用户授权的实验对象和必要数值，引用事件ID并可定位。结构化实验建议由用户检查后执行，不执行模型输出代码。

## 11. 独立科学与工程验收

| 对象 | 方法 | 门槛 |
|---|---|---|
| 前向与梯度 | 小算例、独立NumPy、解析及有限差分 | 平滑双精度解析对照 abs1e-8/rel1e-6；有限差分另定；断点单测 |
| PPO | 正负优势、裁剪边界、GAE终止/截断、旧概率冻结 | 每个分支有可计算期望 |
| SAC | tanh修正、双Q、停止梯度、Actor路径、alpha | 数值、梯度与更新对象全部正确 |
| Adam | 独立公式重算 | 一二阶矩、step、更新量与参数相符 |
| Trace | 开启/关闭追踪与样本聚合对照 | 相同状态得到相同更新 |
| Checkpoint | 保存关闭重载；后续若干步对照 | 原分支复算一致；修改只来自记录的干预 |
| Physics | FK、量纲、能量/阻尼、限位、步长收敛 | 渲染与仿真一致；误差量化，不把稳定当物理正确 |
| 3D | 随机点回算、选择关联检查 | 曲面、节点、轨迹值与内核一致 |
| Product | 创建→训练→检查→分支→导出→导入 | 真实E2E贯通，非模拟API |
| Resilience | 取消/暂停/断线/损坏包/超预算 | 状态明确、无静默数据损坏 |

至少5个预先登记种子报告所有表现、失败、中位数和离散程度；算法比较同时报告交互次数和耗时。不得仅展示最好一条曲线。

性能目标（实现后实测）：选择/切换约100ms；参考网络单次完整检查约1s；1080p3D稳定30FPS、争取60；曲面/训练异步可取消；持续运行无状态串用和明显内存泄漏。参考机器配置与模式一并报告。

## 12. 小规模实用性核查

建议4–6名目标学习者+1名有RL基础的内容核查者。观察能否定位梯度来源、解释PPO裁剪与SAC冻结、创建对照并导出复现。记录真实耗时、错误与反馈后修改。此规模支持可用性观察，不声称统计学证明教学效果。需要真实参与者时向用户说明；不能生成虚假反馈。
