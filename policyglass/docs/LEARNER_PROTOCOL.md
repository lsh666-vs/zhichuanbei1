# 真实学习者核查：待参与

用户已于本阶段明确要求先留空，后续再提供人数。当前参与者数、访谈、任务成绩、专家结论均未采集；本文件是操作方案，不是研究结果。不能用自动浏览器测试、机器审查或模型回答替代真实反馈。

建议4–6名已学过神经网络的成年学习者，另1名有强化学习基础的内容核查者。用户自行联系；不在仓库记录姓名、电话、学生号、原始录音或可识别信息。开始前说明目的、自愿退出和记录范围，征得参与者对匿名任务记录的同意。若用于正式研究/发表，先由用户按其机构要求确认伦理与同意程序，本地可用性观察不能充当获批研究。

一次约25–35分钟：先说明计算/回放/续训与参考模式，然后独立完成以下任务。主持人只记录实际操作和求助，不代答。

1. 从一个已保存PPO事件定位样本、旧概率、优势和裁剪分支；用真实事件说明为什么单样本策略梯度为零时参数仍可能变化。
2. 在SAC固定批次中比较冻结Critic参数与detach Q，指出动作导数及实际更新的对象。
3. 从相同origin创建一个单变量分支，先写预测，再实际更新，引用事件解释差异。
4. 保存笔记并导出，关闭实验，在空store导入后重算，说明旧来源ID和新本地事件的区别。
5. 自由探索一个3D视图，同时找到二维原始值；记录不清楚、误读、键盘或动效问题。

每项记录匿名编号、开始/结束时间、完成/部分/未完成、实际求助次数、具体卡点、所引用对象ID、参与者原话（经同意）、主持人观察及版本/环境。意见与事实分列。专家另核查PPO、SAC、优化器和物理边界的内容，不把“好看”当科学正确。

后续将经同意的匿名记录填入 `evidence/learner-records.json`，初始 `records:[]`。逐项对照问题实施修订后再复测，保留前后版本。此样本只能支持可用性观察，不能声称统计学教学效果、普遍学习增益或独立同行评审。
