# 神经网络与实际曲面

用户指出默认长方体和空白网格无法展示网络结构。r4取消长方体默认表示：每个模型直接显示输入、隐藏层、输出神经元以及相邻层的全部权重连接。参考Actor为15→64→64→6，共149个神经元、5,440条权重连接和134个偏置。64个隐藏单元分列排布以便逐一选择，没有用少数图标代替其余单元；这是概念布局，不是物理坐标。

连线青绿/蓝表示真实权重正/负；神经元显示所选真实样本的激活，反向模式则显示该事件保存的梯度。未运行前向时单元呈中性色，不生成虚构激活。Actor六个输出标为μ及raw logσ；它们还需经过分布、重参数化及tanh/力矩缩放，不直接冒充六个动作。

单击神经元或连接，图中高亮相应路径，并显示W[j,i]、b[j]、x[i]和h[j]。偏置用常数输入1的虚线路径标出，下方显示z=ΣWx+b。可以通过层/单元/输入选择器定位全部坐标，展开当前单元全部入边，或打开完整事件张量。

未有Trace时直接读取所选实验/检查点的真实参数，不必先训练。参数接口的可选checkpoint必须属于该实验；返回格式仍是模型到参数的映射。已有完整层事件时，W、b、激活和梯度全部取自同一事件，尤其SAC更新Critic之后的q1_actor_path不与旧检查点参数混合。实际来源事件、Trace或检查点ID随数值显示。

“计算Actor前向”执行真实网络并保存前向记录，参数与优化更新计数不增加。“修改此权重/偏置”把准确路径和索引填入受控分支表单；检查新的绝对值后创建子分支，原实验保留。

参数快捷修改始终绑定所选的完整父检查点：若图中正在回放历史事件，点击后先切换为该检查点的真实W/b，清除不匹配的激活，并用父状态原值填表。表单显示父检查点、原值、拟写入绝对值与入口历史事件；切换检查点、Trace或选中坐标后旧交接失效，需要重新从网络选取。SAC post-critic事件是中间阶段，只能回放其一致的参数/激活；快捷修改转到完整检查点，不合成中间检查点。

工作台首屏的唯一计算控制条区分“看一次Actor前向”（不更新参数、不推进物理）与“启动/继续计算”（记录真实更新，使用明确的迭代预算和计算模式）。预算/模式在同一控制条展开；暂停、恢复、取消及真实任务状态始终可到达。记录完成后，“检查Actor前向”定位实际Actor层，“检查实际参数更新”定位已保存的优化器事件；仅前向不会宣称梯度就绪。缺前提的阶段在原位提供真实计算入口，不自动训练。并发读取不会提前清除尚在进行的来源加载/计算状态。

网络工具栏的“专注网络检查”收起次要导航，让画布、同一份连接读数/来源和修改入口同屏。“聚焦所选路径”按当前模型的上一层全部输入节点与目标单元实际概念坐标范围定位；其余连接淡化但保留。“返回总览”保留选择。所有网络总览将完整模型平铺，保留全部节点/连接，以模型身份标签为主；进入所选模型/路径后渐进展开相关层和W/b标签。Esc退出专注并把焦点返回入口；深层张量入口返回工作台的原检查器，不复制另一套参数状态。相机即时定位，无动画过渡，减弱动效模式同样适用；这些布局/相机操作不触发网络计算、训练或模型写入。

双Q在SAC视图进入时异步计算真实动作网格；PPO视图明确说明其使用V(s)，并提供新建SAC入口。局部损失缺少批次时提供记录一次真实更新的入口；批次、检查点和Trace就绪后计算。自动计算等待选中来源就绪，避免训练完成时错误请求仍无批次的旧初始检查点。取消与手动重新计算保留。

曲面顶点来自服务器返回的实际网格，支持旋转、缩放和点选。所选网格点在曲面中标记，二维表显示原始坐标和Q/loss。高度按当前范围缩放，局部损失只表示两个标量参数方向的固定条件切片，不能外推为完整地形。真实平缓结果不会替换成预制山峰图片。

每张曲面保存完成计算时的完整请求条件。动作轴、固定动作、损失路径/索引、范围或分辨率变化后，立即隐藏旧图、旧表与导出入口，提示“设置已变更，待重算”；原样恢复条件可继续查看相同结果。结果摘要和图中轴名使用该次网格的真实动作维/Nm或参数方向，列明检查点与固定条件；导出包含同一份请求快照。过期异步响应不能重新显示为当前结果。Q1/Q2/min只是同一网格的显示选择，不触发重算；首次进入满足前提的视图仍自动计算。

曲面图例与标记使用固定身份色：Q₁青绿、Q₂蓝紫、min琥珀、loss紫红，单显与同显不改变身份。画布旁的探针与下方二维表共用同一网格索引；i/j有名称和范围，聚焦探针后可用←→调i、↑↓调j。Canvas点击以真实命中点在命中三角形三个顶点中选择最近者，显示“吸附到实际网格点”；x/y及Q/loss始终读取服务器离散原数组，不把插值或显示高度当重算值。loss的x/y是所示参数方向的偏移。导出同时保留完成请求和当前离散选择；草稿失效、来源切换或取消后探针与旧结果同步隐藏。

优化器Inspector可在同一事件内选择真实参数矩阵行/列、偏置向量索引或alpha标量，控件依据记录的before.shape限制坐标；不切回layer、不触发训练或修改。醒目摘要直接呈现记录的before→delta→after，并区分raw_gradient（裁剪前批梯度）与gradient（裁剪后、送入Adam）。Adam历史与原始完整张量/复制入口按需展开，所有数值均来自同一保存事件，不重新模拟Adam。坐标仍复用全局selection，矩阵/向量/标量切换时规范越界坐标并提示；完整来源及已有参数交接失效保护继续生效。
