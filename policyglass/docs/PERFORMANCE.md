## 不可变 Trace 投影修订

完整原始 Trace、原有对象 ID 和科学数值保持不变。保存时额外派生 `index.json`、`frames.json`、逐事件 JSON，以及包含各文件大小/SHA256 的 manifest。新 SQLite `trace_projections` 行绑定原始 Trace SHA 与 manifest SHA；仅在全部投影原子写入后发布。局部读取每次验证 manifest 和相关投影，不把整个大 Trace 放进内存缓存。完整 Trace 路由仍读取并验证原文件全哈希。

旧 store 没有投影记录时，首次局部请求在每 Trace 的文件锁下校验完整原文件并生成投影。并发读者在发布后直接读取，损坏的旧原文件拒绝迁移；已有投影篡改或缺失时明确拒绝，不静默重建来掩盖损坏。固定对象 ID/文件名、索引范围和解析后的目录边界均检查。

投影本身的 SHA 独立绑定到 SQLite 中原 Trace SHA；另外通过原文件 size/mtime/ctime 快速检测普通原文件变化。该 stat 检查不是原文件每次全哈希的替代承诺。复制整个 store 若改变原文件时间元数据，需要在完整 SHA 核对后重新派生投影；`.pgz` 导入到新 store 不受这一限制。原文件全哈希读取路径始终可发现内容篡改。
