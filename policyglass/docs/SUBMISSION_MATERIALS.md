# 比赛材料素材清单

这是可核查素材索引和演示结构，不是已完成的视频或PDF。用户仍要求暂缓制作两者。个人/队伍/报名资料保留待用户提供，不虚构。

## 可直接展示的主线

从实际机械臂经验选择样本，沿观测归一化、Actor前向、损失、梯度、裁剪和Adam检查来源；引用事件，再从精确origin作单变量分支。改变条件后真实计算，比较原始量与行为，最后导出、关闭、导入并重算。必须把历史回放、实时前向和续训分别读出；不以插值动画代表物理计算或撤销训练。

PPO素材：正负优势、裁剪与Adam动量；SAC素材：更新后的在线Q用于Actor路径、冻结参数和detach Q差异；复现素材：origin/output/最新检查点区别、全部随机/优化器/回放状态、安全导入与同机重新运行。讲解助手只在明确同意后向官方服务发送必要节选；离线可用并不依赖大模型。

只能从 `evidence/dialogue-stage*.jsonl` 及对应manifest追溯真实消息、工具、修复和提交。机器交接/代理指令明确标为机器内容，不能充当三条人类引导链或学习者反馈。若原生导出不足以覆盖比赛要求的三条完整核心人类Prompt链，需从既有真实聊天补充导出；不预先造问答、故意造bug或补写不存在的人类意见。
